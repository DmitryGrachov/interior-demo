# Комплект — рабочее пространство дизайнера

Статическое приложение для планировки, комплектации и закупок. Весь код и ресурсы находятся в `index.html`; установка зависимостей и сборка не требуются.

## Публикация на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. Сайт будет доступен по адресу:
   https://dmitrygrachov.github.io/interior-demo/

После включения Pages новые коммиты в `main` будут публиковаться автоматически.

## Локальный запуск

Откройте `index.html` в современном браузере или запустите из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000/.

Данные приложения хранятся локально в браузере. При переходе с локального файла на опубликованный сайт браузер использует отдельное хранилище.
